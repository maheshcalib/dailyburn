# Dailyburn

Dailyburn is a fitness tracker website designed to help users track their fitness activities and achieve their goals. This application allows users to register, log in, set fitness goals, and visualize their progress.

## Features
- User registration and login
- Fitness goal setting
- Activity tracking
- Progress visualization
- Social sharing features

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation
1. Clone the repository.
2. Run `npm install` to install dependencies.

### Running the App
- Use `npm run dev` to start the development server.

### Running Tests
- Use `npm test` to run the test suite.
